# FrontDesk demo

A static export of the FrontDesk demo: a synthetic inbox (every person and address is made up),
served as plain files with no server and no accounts. Actions run in the visitor's tab only.

Generated by `frontdesk export-demo` from [FrontDesk](https://github.com/ocarlsen/frontdesk).
Do not edit these files by hand; re-run the export instead.
