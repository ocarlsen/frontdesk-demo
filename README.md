# FrontDesk live demo

A static export of the [FrontDesk](https://www.ocarlsen.com/frontdesk.html) demo: 20 synthetic
email threads (every person and address is made up) run through FrontDesk's real normalizer and
triage pipeline, with answers recorded once from Claude Opus 5.5. Generated by
`frontdesk export-demo`; do not edit by hand.
